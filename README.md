# BooHoo

This project is from the Jame Gam Game Jam at HackClub, with the theme "I'm Just a Little Guy", and a tiny useless ghost fits it as this ghost is small and little! This ghost (or the little guy) is trying to scare a human who is sleeping in this game.

## How to play and about the project
Use WASD to move, use E to interact with objects, use shift to sprint, and use Q to let out a quick squeak! Your goal is to fill the scare meter by using different scare combos to scare the human, then say "BOO!" using E at the human once the scare meter is full. Make sure you don't use the same move twice or scare while the detection bar is red! There are 3 different endings, but no spoilers! You've got to figure them out yourself. AI was used for creating the original project structure (no code just library imports), resolving merge conflicts, and helping me with the math and physics functions.

This project was built using TypeScript, Vite, and HTML canvas, all made in 3 days. You can visit and play the game at https://boohoo-mauve.vercel.app/
